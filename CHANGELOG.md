## [1.0.0] - initial public release (unreleased)

### Added

- Claude Code session transcript (JSONL) to .curt converter, with CLI
  (file / directory / glob inputs, `-o/--out`, `--stdout`) and a library
  API (`convertTranscript`, `serializeResult`, `resolveOutputName`).
- `tool-linkage` extension emission: assistant `toolCalls[]` linked to
  `role: "tool"` result messages via `toolCallId`.
- Round-trip self-check before every write (`CURT_CONVERT_SELFCHECK=0`
  to skip).
- Bulk collision safety: inputs that would produce identical output names
  (parent + sidechain sessions share a `sessionId`) get a deterministic
  path-hash suffix instead of silently overwriting.

### Changed

- Version jumps from the internal 0.1.0 straight to 1.0.0 for the initial
  public release: the JSONL mapping is complete and corpus-verified
  (1167 sessions), the suite is green (30 tests), and the CLI/API surface
  is considered stable. Note: sample .curt files generated by earlier
  builds carry `generator: "curt-convert@0.1.0"` (including any published
  on the dot_curt site); the site sample should be regenerated with 1.0.0
  in a follow-up — the generator string is metadata only and does not
  affect parsing.
